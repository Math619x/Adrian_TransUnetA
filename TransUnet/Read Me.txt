https://github.com/mkara44/transunet_pytorch/tree/main

Primero tener la version de python:
Python 3.6+

Instalar en su entorno virtual los requerimentos en el siguiente archivo txt:
pip install -r requirements_fftransunet.txt

En las siguientes direcciones:
../transunet_pytorch/trainset/img
../transunet_pytorch/trainset/mask
Colocar las imagenes en formato .npy, de cada imagen (no importa el nombre
de las imagenes, solo deben corresponder con su mascara segmentada).

Ej de una imagen en cada carpeta qe corresponde con su mascara:
../transunet_pytorch/trainset/img/subj_1slice_11.npy
../transunet_pytorch/trainset/mask/subj_1slice_11.npy

De manera similar, en la siguiente direccion:
../transunet_pytorch/testset/img/subj_31slice_11.npy
../transunet_pytorch/testset/mask/subj_31slice_11.npy
Colocar las imagenes para realizar las pruebas.

NOTA:En estas carpetas se deben colocar todas las imagenes, no en subcarpetas.

../transunet_pytorch/results/
En donde se guardaran las imagenes que se generen en el modelo.

--------------------------------------------------------------------------------

Antes de correr el modelo, verificar que las imagenes sean de las dimensiones
correctas, en este caso las imagenes son de 256x256, en 3 canales (RGB).
En caso contrario, ajustar esto en el archivo que se encuentra en:

../transunet_pytorch/config.py

Donde podremos ajustar la dimension de la imagen de entrada, ademas de parametros,
como:

-Batch_size
-Epoch
-Learning_rate
-in_channels (canales de entrada, en este caso 3)
-out_channels (canales de salida)
-head_num (Cabezales de atencion en la capa de transformadores)
-mlp_dim (dimension de Multi-layer perceptron del transformador)
-block_num (bloques de transformadores)
-class_num (clases que se utilizan en las imagenes incluyendo el background de la imagen)

NOTA: En el archivo, se muestran 2 veces los mismos parametros, siendo 
los segundos, los originales que venian en el archivo, y los primeros son
los que se utilizaron para el experimento de la FF-TransUnet.

--------------------------------------------------------------------------------

En el archivo en la direccion:

../transunet_pytorch/fuzzy_control.py

Se encuentra todo el control difuso que se implemento para la modificación del
parametro alfa, el cual se encarga del peso que se le da a cada clase para
enfocarse en clases que tienen menos datos y por tanto, son mas dificiles de 
segmentar. 

Se pueden ajustar los rangos de las 2 entradas que se tomaron para este experimento.
Las 2 entradas son:
1)class_sizes
2)focal_delta

En donde 1) esta definida en el rango de 0 a 1, es decir, el tamaño de cada clase,
respecto al total. Para este caso, es un valor fijo ya que siempre tendremos 
el mismo tamaño de clase en tanto usemos las mismas imagenes. Pero si se utilizan
diferentes imagenes, ya sea de otra base de datos, o haciendo cross fold, se debe 
calcular el total de pixeles, y el total de pixeles que pertenecen a cada clase,
para obtener el tamaño de cada clase.

En 2), se calcula la diferencia entre la perdida en la epoca "n" y la perdida en la
epoca "n-1". Para obtener el rango se utilizaron varios experimentos para observar 
los rangos en los que se encuentra esa diferencia. Por lo que su rango queda definido
entre -0.3 y 0.35. 

La salida del sistema arrojara un ajuste de alpha entre los rangos de -0.5 a 0.5.
Este valor es el que se sumara al alpha de cada clase, para darle mayor peso o menor
segun sea el caso.

Para comenzar con el entrenamiento, entrando en terminal,
primero entramos en el entorno virtual que tengamos
todas las dependencias:
conda activate (nombre del entorno virtual)

NOTA: yo use: conda activate unetpytorch

Y acceder a la carpeta en donde tengamos la direccion:
cd ../transunet_pytorch/
NOTA: mi direccion fue: cd /home/graciela/Adrian/TransUnet/transunet_pytorch/

Ya en la carpeta, correremos el siguiente comando en terminar:
python main.py --mode train --model_path ../transunet_pytorch/model/model1/pth --train_path ../transunet_pytorch/trainset --test_path ../transunet_pytorch/testset

NOTA: la direccion que yo use es la siguiente:
python main.py --mode train --model_path /home/graciela/Adrian/TransUnet/transunet_pytorch/model/model1.pth --train_path /home/graciela/Adrian/TransUnet/transunet_pytorch/trainset --test_path /home/graciela/Adrian/TransUnet/transunet_pytorch/testset

Cuando el entrenamiento finalice, podemos utilizar el siguiente comando
en terminal para obtener las imagenes de inferencia:
python main.py --mode inference --model_path ../transunet_pytorch/model1.pth -- image_path ../path a tu base de datos de test

NOTA: la direccion que yo use es la siguiente:
python main.py --mode inference --model_path /home/graciela/Adrian/TransUnet/transunet_pytorch/model/model1.pth --image_path /home/graciela/MCTrans/data/medical/pannuke/split-images-npy/2/
